# The body set

One rigged `.glb` per body preset. Every depth export uses these; there is no
fallback to the built-in swept anatomy, because an export of that is a picture
of a mannequin and the trap is that the file still appears.

Generated by `tools/make_bodies.py` from [Anny](https://github.com/naver/anny)
(Apache 2.0 code over MakeHuman's CC0 assets), so they are freely
redistributable and they are here rather than left to be built - a fresh clone
can export without first installing torch. Rebuild or replace them with:

    pip install anny
    python3 tools/make_bodies.py bodies/

Any rigged `.glb` named after a preset works in their place - an MPFB2 export,
SMPL-X, a Mixamo character - as long as `mesh_backend.resolve_bones` can map
the armature. Check one with:

    python3 mesh_backend.py --inspect bodies/male_average.glb
    python3 tests/check_glb.py bodies/*.glb
